## Icon

Generated a background pattern on https://lumisphere.app/mesh-gradient-generator. Converted to icons on https://prod0.dev/tools/tauri-app-icon-generator with padding Auto (10%).

To update the icon on macOS, placing the files isn’t enough. Do:

```shell
write-261018-kwui % cd src-tauri
src-tauri % cargo clean
     Removed 4161 files, 2.4GiB total
src-tauri % cd ..
write-261018-kwui % pnpm tauri dev
```
