## Why Tauri?

### PWA

In a PWA, you can open a file, but you have to grant permission to access other files one by one. This is too cumbersome when an `.md` file contains images. You might be able to grant access to the folder containing the `.md` file, but you still have to select the folder and the `.md` file separately, opening the file chooser twice.

Also, a PWA is shown in a browser window. It is not able to control macOS’s menu bar.

### Flutter

Flutter’s multi-window support and desktop WebView are not yet mature enough.
