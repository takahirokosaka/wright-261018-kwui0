## Problem

The app icon’s quality wasn’t good.

## Solution

- Using [Icon Composer](https://developer.apple.com/download/all/?q=Icon%20Composer), added macOS 27 effect
- According to [this](https://gist.github.com/ansarizafar/6fa64f44aa933794c4d6638eec32b9aa), exported 16x16, 32x32, 64x64, 128x128, 256,256, 512x512, 1024x1024 png images and generated `write.icns`
- Edited `tauri.conf.json`
```json
"icon": [
	"icons/write.icns"
],
```
- `pnpm tauri build`
