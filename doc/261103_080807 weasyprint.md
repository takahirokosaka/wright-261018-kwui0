# WeasyPrint

[`twoup.css`](<./261103_080807 weasyprint.assets/twoup.css>) is an example of mixing two-up and single full-width printing. Export the demo .md file as Untitled.html then:

<div class="terminal"><span style="color: var(--ansi-bright-magenta);">Desktop</span><span style="color: var(--ansi-bright-blue);"> %</span> <span style="color: var(--ansi-green);">weasyprint</span> -e utf-8 --stylesheet=twoup.css <span style="text-decoration: underline;">Untitled.html</span> <span style="text-decoration: underline;">Untitled.pdf</span>
</div>
